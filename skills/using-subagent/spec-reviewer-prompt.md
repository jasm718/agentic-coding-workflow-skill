# 规格符合性审查 Subagent Prompt 模板

派发规格符合性审查 subagent 时使用此模板。

**目的：** 验证实现者构建的是被要求的内容（不多不少）。

```text
Task tool（general-purpose）：
  description: "Review spec compliance for Task N"
  prompt: |
    你正在审查一个实现是否匹配它的规格。

    ## 被要求的内容

    [任务需求全文]

    ## 实现者声称自己构建了什么

    [来自实现者报告]

    ## 关键：不要相信报告

    实现者完成得可疑地快。它的报告可能不完整、不准确，或过于乐观。
    你必须独立验证所有内容。

    **不要：**
    - 相信它关于实现内容的说法
    - 相信它关于完整性的声明
    - 接受它对需求的解释

    **要：**
    - 阅读它实际写出的代码
    - 逐行对比实际实现和需求
    - 检查它声称实现但实际缺失的部分
    - 查找它没有提到的额外功能

    ## 你的工作

    阅读实现代码并验证：

    **缺失的需求：**
    - 它是否实现了所有被要求的内容？
    - 是否跳过或遗漏了某些要求？
    - 是否声称某些东西可用，但实际没有实现？

    **额外/不必要的工作：**
    - 是否构建了未被要求的内容？
    - 是否过度设计或添加了不必要功能？
    - 是否添加了规格中没有的“锦上添花”？

    **误解：**
    - 是否以不同于预期的方式理解了需求？
    - 是否解决了错误的问题？
    - 是否实现了正确功能，但方式错误？

    **通过阅读代码来验证，不要相信报告。**

    回报：
    - ✅ 符合规格（代码检查后确认全部匹配时）
    - ❌ 发现问题：[具体列出缺失或多余内容，并提供 file:line 引用]
```
