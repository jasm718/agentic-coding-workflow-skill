# 深模块

来自《A Philosophy of Software Design》：

**深模块** = 小接口 + 大量实现

```text
┌─────────────────────┐
│       小接口        │  ← 方法少，参数简单
├─────────────────────┤
│                     │
│                     │
│       深实现        │  ← 隐藏复杂逻辑
│                     │
│                     │
└─────────────────────┘
```

**浅模块** = 大接口 + 少量实现（避免）

```text
┌─────────────────────────────────┐
│             大接口              │  ← 方法多，参数复杂
├─────────────────────────────────┤
│             薄实现              │  ← 只是透传
└─────────────────────────────────┘
```

设计接口时，询问：

- 我能减少方法数量吗？
- 我能简化参数吗？
- 我能把更多复杂度隐藏到内部吗？
